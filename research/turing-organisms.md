# Turing Organisms and Bounded Universality

`OrganismTuringMachine` gives a living object a finite transition table, tape, step budget, halting result, complexity estimate, and a bounded self-simulation primitive. The proof suite checks acceptance, rejection, step limits, direction validation, self-simulation, and a positive universality score.

This is a bounded computational contract, not an assertion that a production organism is an unrestricted universal computer. Kolmogorov complexity is represented by a structural proxy and should be interpreted comparatively.
