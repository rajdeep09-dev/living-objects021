# v16 Prompt-Conditioned Native JSON Follow-up

**Status:** Observed negative result.  This record reports one finite local
follow-up to v15.  It does not revise the v15 evidence and does not establish
reasoning, coding, useful BEAST assistance, or a GGUF/Ollama runtime.

## Question and protocol

The v15 follow-up asked a narrow question: whether the existing native
28,864,544-parameter byte transformer could emit controller-shaped JSON when
the declared instruction and input for each source-disjoint holdout row were
provided as a prompt.  The run used the v15 local checkpoint as a read-only
native initialization artifact; it did not download weights or data, call a
network service, start a worker, execute generated text, alter the primitive
registry, or admit guidance to evolution.

The runner changed only the supervised loss surface.  It constructed a prompt
from the checked-in row's `instruction`, `input`, and `controller_json:`
delimiter, then applied cross-entropy loss to target JSON bytes only.  Prompt
labels used PyTorch's ignore index.  The held-out evaluator greedily decoded
one candidate for each of the ten source-disjoint prompts, forced only an
opening `{` formatting prefix, and sent each unmodified candidate through the
existing fail-closed controller.  No task-correctness or BEAST-improvement
metric was measured.

## Exact result

The target-only held-out NLL **worsened** from **0.2009989224** before tuning to
**0.2654667787** after tuning.  The final observed training NLL was
**0.0652713999**, which is not a held-out quality result.  All ten held-out
generations were 513 bytes, had the same digest
`33b4c33ffaf578fb01e4c9e5e13dfb96c5536b8da950cc1efbd06dfb095851d0`, and
failed controller parsing as `invalid_json`.

| Held-out criterion | Result |
|---|---:|
| Valid JSON | **0 / 10 (0%)** |
| Exact controller schema | **0 / 10 (0%)** |
| Default-profile controller admission | **0 / 10 (0%)** |
| Controller result | **10 / 10 `invalid_json`** |
| Primitive admitted or executed | **0** |
| Task correctness / BEAST improvement measured | **false** |

> The v16 protocol did not improve the held-out target NLL and did not produce
> a single valid or controller-admitted response.  It is therefore retained as
> a prompt-conditioned negative result, not a model capability milestone.

## Reproduction and retained artifacts

Run the finite experiment locally from the repository root.  The v15 checkpoint
is local-only and deliberately excluded from Git history; without it, this
exact follow-up cannot be rerun from a fresh clone.

```bash
APP_ENV=test python3 -m agnes_brain.instruction_tune_28m \
  --base-checkpoint reports/v15/beast-brain-28m-json-instruction-20260819/checkpoint-latest.pt \
  --output-directory reports/v16/prompt-conditioned-json-instruction-tuning-28m-local \
  --max-wall-seconds 1800 --max-steps 6000 --batch-size 2 \
  --checkpoint-interval-steps 100
```
