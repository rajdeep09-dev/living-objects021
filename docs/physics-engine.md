# Evolving Digital Physics

`UniversePhysics` is a small digital-physics kernel. Laws are named transformations over an ecosystem, and a mutation is accepted only when a `FormalSafetyProof` reports a non-empty invariant and a passing bounded check. The default law set preserves token totals, causal generation order, entropy-like behavioral diversity, and an information budget.

`ParallelUniverse.branch()` deep-copies the parent law set, replaces the triggering law, records parent lineage, increments branch generation, and calculates fingerprint divergence. This is a software-versioning analogy for alternate physics, not a physical cosmology model. Benchmark evidence reports code-level law regimes and provenance.
